ArtemisSurf

A minimal, transparent, privacy-first desktop web browser written in Python. You stay signed in to sites like Google and YouTube, while history, cache and download history are never kept.

01How it works

ArtemisSurf’s own code is Python. Page rendering comes from Chromium through Qt, which is why modern sites and sign-ins work.

ArtemisSurf (this repo)window, address bar, bookmarks, privacy wipe
PyQt6Python bindings for Qt
Qt WebEngineQt’s browser component
Chromiumrenders pages, runs JavaScript, stores cookies

02Install in 4 steps

The same four steps work on every system. Only the commands to prepare your machine differ, so pick your OS below.

Clone

Download the source with Git.

git clone …
Create a venv

A private Python environment for the project.

python -m venv .venv
Install

PyQt6 and the WebEngine.

pip install -r requirements.txt
Run

Launch the browser.

python main.py

03Using it

Keyboard shortcuts
Alt + ← / →Back / Forward
F5 or Ctrl+RRefresh
Alt + HomeHome page
Ctrl + LFocus address bar
Ctrl + DBookmark this page

Drag the toolbar to move the window, double-click it to maximize, and use the ⚙ button to change the home page, opacity or wallpaper. On macOS, use Option in place of Alt if the shortcut doesn’t respond.

Logins (cookies, local storage)kept
Bookmarks & settingskept

Download history listnever stored

04Troubleshooting

Google says “This browser may not be secure”

Google sometimes blocks embedded Chromium browsers. ArtemisSurf sends a Chrome-style user agent to reduce this. If it still happens, raise the Chrome version number in USER_AGENT inside artemis/config.py.

“Could not load the Qt platform plugin xcb” (Linux)

A system library is missing. Install the Debian/Arch prerequisites above, especially libxcb-cursor0 / xcb-util-cursor. You can also try:

QT_QPA_PLATFORM=xcb python main.py
The window isn’t transparent (Linux)

Transparency needs a compositing window manager. GNOME, KDE and most full desktops have one. Minimal setups may need a compositor such as picom.

Black or flickering page (GPU issues)
QTWEBENGINE_CHROMIUM_FLAGS="--disable-gpu" python main.py

On Windows PowerShell, set it first with $env:QTWEBENGINE_CHROMIUM_FLAGS="--disable-gpu".

ModuleNotFoundError: No module named 'PyQt6'

The virtual environment isn’t active. Run the activate command from your OS tab, then pip install -r requirements.txt again.
